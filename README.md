# مدیریت کسب‌وکار محمد
نسخه اول یک داشبورد وبی مستقل و بدون کتابخانه خارجی.

## انتشار با GitHub Pages
1. یک Repository جدید در GitHub بساز.
2. فایل `index.html` را در ریشه Repository آپلود کن.
3. از Settings → Pages، گزینه Deploy from branch را انتخاب کن و branch اصلی / root را فعال کن.
4. چند لحظه بعد لینک GitHub Pages ساخته می‌شود.

این نسخه فعلاً داده‌ها را در LocalStorage مرورگر نگه می‌دارد. برای API، احراز هویت، دیتابیس، انتشار خودکار و پرداخت باید Backend امن اضافه شود.
